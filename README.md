# IT Help Desk Knowledge Base

**Project 3: Specialization Project (IT Support)** · BSIT Industry-Ready Portfolio

A self-help website with step-by-step fixes for common computer, network, printer, account, and security problems. Each article follows a standard troubleshooting format used by IT help desks.

🌐 **Live Demo:** PASTE-YOUR-LINK-HERE

## 🎯 Purpose
Help desks receive the same problems again and again. A knowledge base lets users fix simple issues themselves and helps technicians follow a consistent process. This project shows my IT Support skills for my target role: **Help Desk Technician**.

## 📋 Article Format
Every article follows the same structure:
1. **Problem**
2. **Possible Causes**
3. **Diagnostic Procedure**
4. **Solution**
5. **Lesson Learned / Prevention**

## 📚 Articles
| # | Problem | Category |
|---|---|---|
| 1 | No internet connection (Wi-Fi connected but no internet) | Network |
| 2 | Computer is very slow | Performance |
| 3 | Computer won't turn on or has no display | Hardware |
| 4 | Printer is not printing | Printer |
| 5 | Forgot password or account is locked | Accounts |
| 6 | Suspicious email or message (phishing) | Security |
| 7 | Website design (CSS) is not loading ⭐ | Software |
| 8 | Image is not showing on a web page ⭐ | Software |

⭐ Based on problems I personally solved while building my portfolio.

## ✨ Features
- Instant **search** by keyword
- **Category filters**
- Expandable articles (accordion)
- "Still not fixed?" guide for submitting a proper ticket
- Mobile-friendly layout
- Text is escaped before display to prevent HTML injection

## 🛠️ Technologies
HTML, CSS, JavaScript, Bootstrap 5, GitHub Pages

## 📁 Project Structure
```
it-helpdesk-kb/
├── index.html      → page layout
├── css/style.css   → design
├── js/articles.js  → article content (data)
└── js/app.js       → search, filters, and display
```
Articles are stored as data in `articles.js`, so new articles can be added without changing the HTML.
